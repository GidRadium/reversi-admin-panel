## Основные классы и идеи.

#### game
- `ReversiRules`
  - Определяет любые изменения игры.
  - Проверяет корректность ходов.
  - Отдаёт последствия хода.
  - Не меняет состояние объектов.
- `Game`
  - В себе хранит историю, доску, состояние и прочее.
  - Поддреживает инвариант игры. Единственный класс изменяющий состояние игры.
  - Сам ничего не решает - исполняет решение ReversiRules.
  - Ничего не знает о том, какие игроки играют, какая по счёту игра и т.п.

#### application
- `IGameRepository`, `IPlayerRepository`
  - Системы хранения игр и игроков.
  - их реализуют `InMemoryGameRepository` и `InMemoryPlayerRepository`
  - Также будут реализовывать базы данных.
- `AdminService`
  - Выполняет команды пользователя: создаёт, изменяет, удаляет игры и пользователей
  - Считает статистику и прочее.

#### application.database
- `DatabaseFactory`
  - Создаёт подключение к SQLite.
  - Инициализирует таблицы базы данных.
  - `PlayersTable`, `GamesTable`, `MovesTable`
    - Описывают структуру таблиц базы данных через Exposed.
    - Хранят игроков, состояние игр и историю ходов.
  - `GameSnapshotCodec`
    - Преобразует состояние доски в формат, подходящий для хранения в базе данных, и обратно.

#### presentation.cli
- `Cli`
  - Работает с входными от пользователя данными.
  - Парсит, преобразует в вызовы AdminService.
  - Показывает нужные данные по требованию пользователя.

#### presentation.gui
- `Gui`
  - Создаёт главное окно приложения.
  - Собирает и размещает основные элементы интерфейса: игроков, текущую игру и список игр.
  - Передаёт действия пользователя в соответствующие панели.
  - Сам не содержит бизнес-логики.
- `PlayersPanel`
  - Отображает список игроков.
  - Позволяет создавать и удалять игроков.
  - Показывает локальную статистику выбранного игрока.
  - Передаёт действия пользователя в GuiViewModel.
- `GamesPanel`
  - Показывает список созданных игр.
  - Позволяет удалить выбранную игру.
  - Передаёт действия пользователя в GuiViewModel.
- `GamePanel`
  - Отображает состояние выбранной игры.
  - Показывает игровую доску, счёт, текущего игрока и историю ходов.
  - Позволяет выбрать игроков для новой игры и создать её.
  - Передаёт ходы пользователя в GuiViewModel.
  - Отображает доступные для хода клетки.
- `GuiViewModel`
  - Связывает GUI с AdminService.
  - Хранит GuiState.
  - Выполняет операции GUI через AdminService.
  - После изменения данных обновляет GuiState.
  - Не знает о Swing и не зависит от конкретных компонентов интерфейса.
- `GuiState`
  - Хранит состояние GUI: список игроков, игры, выбранные объекты, доступные ходы, статистику и сообщения.
  - Не содержит логики изменения игры или игроков.
  - Используется GuiViewModel и графическими компонентами для отображения актуального состояния.
